# Ollama


Pull a model locally
````
ollama pull qwen2:7b
````

Start Ollama

```
ollama serve
```

## Python venv

Create and activate the virtual environment:

```
python3.12 -m ai/hugging-face/agents-course/venv python-code/venv
source ai/hugging-face/agents-course/python-code/venv/bin/activate
```
